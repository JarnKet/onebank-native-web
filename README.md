# OneBank Web

BCEL OneBank's web app: shared group accounts, roles and approvals, transfers, bills, salary
and e-cheques. It is a standalone front end on mock data. See `PRODUCT.md` for what it does,
`DESIGN.md` for how it is designed, and `CLAUDE.md` for how the code is organised.

```bash
pnpm install
pnpm dev        # http://localhost:7001 — any username/password signs in
pnpm test
pnpm run check
pnpm build
```
